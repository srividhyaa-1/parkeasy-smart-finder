**Parkeasy – Smart Parking Locator**

An IoT-enabled smart parking system that helps users find available parking slots in real time.

**About the Project**

Parkeasy is a smart parking solution designed to display parking slot availability and help users locate suitable parking areas easily.

**Features**

- Real-time parking slot availability
- Parking area selection
- Parking slot status display
- Location-based parking assistance
- User-friendly interface

**Technologies Used**

- React
- TypeScript
- Vite
- Tailwind CSS
- ESP32
- Ultrasonic Sensors

**How It Works**

Ultrasonic sensors detect whether a parking slot is occupied or available. The ESP32 collects the sensor data and the web application displays the parking slot status in real time.

**Future Enhancements**

- Online parking slot booking
- Google Maps integration
- Distance calculation
- User authentication
- Firebase real-time database integration
